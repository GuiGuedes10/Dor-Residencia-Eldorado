Ranqueador semântico — demo

Digite uma intenção. O ranqueador (TF-IDF de n-gramas, extension/tfidf.js) ordena os links reais da PUC por similaridade — tudo no navegador, sem modelo nem servidor. Sinônimos puros (ex.: advogado → Direito) são o limite deste ranqueador leve; a fase 2 (embeddings neurais, 68%) resolve.
